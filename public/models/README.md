# 3D Teddy Bear Model Integration Point

To use an external 3D Teddy Bear model:
1. Place a `.glb` or `.gltf` model here named:
   `teddy.glb` (path: `/public/models/teddy.glb`)
2. The website will automatically detect and load it, wrapping it in the holographic projection, rim lighting, floating particles, and tap interactions.
3. If no file is provided, the website seamlessly falls back to the high-detail procedural plush holographic teddy bear.
